### 3.5 Create `packages/validation/CLAUDE.md`

```markdown
# Validation Package — Claude Memory

## Purpose
Extends auto-generated Zod schemas from `packages/database/generated/zod/`
with OpenAPI metadata for API documentation.

## Pattern
```typescript
// Import generated base schema
import { UserSchema } from 'packages/database/generated/zod'

// Extend with OpenAPI metadata
export const UserResponseSchema = UserSchema.extend({...})
  .openapi({ title: 'User' })
```

## Key Dependencies
[Extracted from package.json]
- `@asteasolutions/zod-to-openapi` — OpenAPI metadata
- `zod` — validation

## Conventions
- All schemas must have `.openapi()` metadata for API documentation
- Export both schema AND inferred type: `export type User = z.infer<typeof UserSchema>`
- Group schemas by domain (matches Prisma models)

## Do Not
- Never use `class-validator` — Zod only
- Never duplicate validation logic that exists in generated schemas — extend them
- Never manually maintain schemas that can be generated from Prisma
```
