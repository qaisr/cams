# PPCC Enterprise AI Framework

## What This Folder Contains

This folder is the source of truth for local AI delivery guidance in this repository:

- Agent definitions (`.claude/agents`)
- Slash commands (`.claude/commands`)
- Standards and policies (`.claude/standards`)
- Reusable workflows (`.claude/workflows`)
- Architecture and implementation patterns (`.claude/patterns`)
- Code and document templates (`.claude/templates`)
- Supporting docs (`.claude/docs`)
- CANS platform feature reference (`.claude/project-features.md`)

The canonical master index is `.claude/CLAUDE.md`.

## About the CANS Platform

**This repository is a production-ready CANS platform.** The foundational infrastructure, auth, RBAC, frontend pages, UI component library, testing, and tooling are **already implemented**. Do not create epics to rebuild them.

> See `.claude/project-features.md` for a full inventory of built-in features.

New projects using the CANS platform should begin with:
1. `/infra-setup` — validate your local environment
2. `/create-specifications` — generate specs from your requirements
3. `/create-epics` — plan your delivery epics

## How to Use This Framework

- **Configuration**: See `docs/CONFIG-ALIGNMENT-GUIDE.md` for unified config strategy
- **Code Quality & Formatting**: See `docs/code-quality-and-formatting.md` for complete formatting standards, pre-commit hooks, and validation
- **Development Guide**: See `docs/DEVELOPMENT-GUIDE-HOW-TOS.md` for example prompts, patterns, and framework usage
- **Build complete app from spec**: Use `/create-epics`, then either `/implement-epic` for S/M epics or `/create-epic-tasks` for L/XL epics
- **Daily development**: Use slash-commands below
- **Standards reference**: See `standards/` folder (loaded lazily on demand)
