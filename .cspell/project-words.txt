# ── Triage guide when cSpell flags an unknown word ─────────────────────────
# Decide per word BEFORE adding it here — do not bulk-add flagged words:
#   1. Real misspelling (e.g. "recieve", "dismissable") → FIX it in the source,
#      never add it here. GB/AU/US spellings are already accepted; if such a word
#      is flagged, the dictionary config is broken — fix cspell.json, not the word.
#   2. Joined lowercase words that are an IDENTIFIER WE OWN (our own variable,
#      prop, or function name — e.g. "apikey", "appuser" written as code we author)
#      → rename to camelCase in the source (apiKey, appUser), don't add here.
#   3. Joined/lowercase token we DO NOT control — a literal credential value,
#      DB role name, connection param, third-party method, CLI string, env
#      placeholder, or intentionally-truncated grep pattern (e.g. redis `setex`,
#      Postgres `sslmode`, `System.getenv`, `grep -i deprecat`, placeholder
#      `myapp`) → keep the literal and ADD it here. Renaming would break it.
#   4. Genuine domain/tech vocabulary, acronym, product noun, or library name
#      (e.g. "Timestamptz", "IDOR", "nuqs", "redocly") → ADD it here.
